# AI-SENTIMENT-ANALYSIS-PROJECT
# AI-Based Sentiment Analysis of Product Reviews

A machine learning-based sentiment analysis system that classifies product reviews into **Positive, Negative, and Neutral** sentiments using Natural Language Processing (NLP) and Machine Learning techniques.

---

## 📌 Project Overview

This project analyzes customer product reviews and predicts sentiment polarity using a hybrid approach that combines text preprocessing, TF-IDF feature extraction, lexicon-based scoring, and machine learning classification.

The system also includes an interactive dashboard for real-time sentiment prediction, analytics, and model performance visualization.

---

## 🚀 Features

* Product review sentiment classification
* Real-time sentiment prediction
* Text preprocessing and normalization
* TF-IDF feature extraction
* Multiple ML model comparison
* Interactive analytics dashboard
* Sentiment distribution visualization
* Confusion matrix and performance metrics
